maplibre-gl-indoor — examples

Each example demonstrates one capability of the plugin.

  • The minimal setup — One indoor GeoJSON, the level control, nothing else. Use the level selector on the right.
  • Several buildings, one map — Three indoor maps are registered; the plugin auto-selects the one in view. Use the buttons to fly between Gare de l’Est, Caserne de Bonne and Grand’Place.
  • Your own layer, level-aware — A custom PoI layer is added on top and filtered by the current level: switch levels and watch the red markers appear only on theirs.
  • Custom indoor style — The default indoor look is replaced by custom layers (blue rooms) passed to IndoorMap.fromGeojson.
  • Plugin events — Every indoor event is appended to the log panel: load a map, switch levels.
  • Straight from a raw .osm file — The building is loaded from an OSM XML export and converted on the fly with osmtogeojson.
  • Search the indoor features — Type a name: results come from the indoor GeoJSON itself, clicking flies to the feature and selects its level.
  • Maps served by a backend — MapServerHandler downloads indoor maps around the viewport from a server. This page needs one at localhost:4001, so it shows the wiring, not data.
